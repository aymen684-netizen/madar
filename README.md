# مدار — تتبّع الأقمار الصناعية

نسخة التطبيق كاملة: كرة أرضية ثلاثية الأبعاد، حركة محسوبة بـ SGP4، بحث بالاسم ورقم NORAD والدولة والأنواع والتاريخ والوقت، تقارير المرور والتحليل متعدد الأيام وتصدير Word بالأعلام.

النسخة المنشورة على Cloudflare: https://madar.aymen684.workers.dev/

## نشر النسخة الكاملة على Cloudflare

في Cloudflare افتح Workers & Pages ثم Create application ثم Import a repository، واختر `aymen684-netizen/madar` وفرع `main`. دليل العمل هو جذر المستودع، وأمر البناء `npm run build` وأمر النشر `npx wrangler deploy`. بعد النشر يظهر رابط workers.dev ويمكن ربط نطاقك وتفعيل النشر عند تحديث main من إعدادات الربط مع GitHub.

أو من جهازك:

```sh
git clone https://github.com/aymen684-netizen/madar.git
cd madar
npm ci --ignore-scripts
npx wrangler login
npm run deploy
```

`wrangler.jsonc` يربط مجلد public بالملفات الثابتة وworker/index.js بتنزيل Word على /api/word.docx. لا يحتاج التطبيق قاعدة بيانات؛ البحث والتقارير محفوظة في متصفح المستخدم، وخدمة Word تعيد الملف دون تخزينه على الخادم.

## GitHub Pages

في المستودع افتح Settings → Pages → Source → GitHub Actions، ثم Actions → Publish GitHub Pages → Run workflow. رابط النشر المتوقع بعد النجاح: https://aymen684-netizen.github.io/madar/

GitHub Pages يشغّل الواجهة فقط: تنزيل Word المباشر والمشاركة يعملان من المتصفح، أما تنزيل Word عبر الخادم فهو متاح في نسخة Cloudflare ويُخفى تلقائيًا على GitHub Pages.

## التطوير والتحقق

```sh
npm install
npm run check
npm run dev
```

مجلد public يحتوي جميع ملفات الواجهة والبيانات والصور والمكتبات. بيانات النسخة الاحتياطية جُلبت في 13 أكتوبر 2026؛ يحاول التطبيق جلب العناصر الأحدث من CelesTrak عند الاتصال. المواقع والتقارير تقديرات من العناصر المدارية المتاحة، وليست قياسات مباشرة أو سجلًا مرصودًا. تصنيف CIS يجمع روسيا ورابطة الدول المستقلة والاتحاد السوفيتي السابق.

راجع public/credits.txt للمصادر والتراخيص. ملفات هوية استضافة ChatGPT ومفاتيح الوصول غير مضمنة.

توثيق النشر: https://developers.cloudflare.com/workers/static-assets/binding/ و https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

الأعلام محفوظة في flags.bundle.zip ويستخرجها أمر البناء تلقائيًا دون تغيير الصور.

خلفية النجوم محفوظة على أجزاء تجمع تلقائيًا في أمر البناء دون تغيير الصورة.

البيانات والمكتبات الكبيرة محفوظة مضغوطة في packed/ ويعيدها أمر البناء بعد التحقق من بصمة SHA-256. جميع ملفات الواجهة الأصلية موجودة في public/، والبيانات والمكتبات تعود كما هي دون فقد.

## تحديث مجموعات الأقمار والعرض الكثيف

يوفّر التطبيق 45 مجموعة، مع دمج الأنواع المختارة في الدليل والتقارير والتحليل. عند تعذّر المصدر يستخدم النسخة المحلية أو تصنيفًا تقريبيًا واضحًا؛ الأنواع التي لا تملك بديلًا تعرض رسالة خطأ. يواصل الدليل عرض الأنواع المتاحة، بينما لا يُنشأ تقرير أو تحليل إذا فشل تحميل أي نوع مختار.

عند تجاوز 1,500 قمر تُحسب المواقع في positions-worker.js وتُعرض جميع المواقع الصالحة كنقاط خفيفة قابلة للاختيار، مع إبقاء القمر المحدد بعلامته التفصيلية. عند غياب دعم هذا العرض يعود التطبيق إلى العرض المحدود السابق. يشمل npm run check فحوص المجموعات والبدائل المحلية وحساب مواقع الفهرس الكامل وتحديث العناصر المدارية وحماية التقارير من النتائج الناقصة.

يمكن تنزيل نبذة عربية عن مدار ومميزاته وحدود دقة بياناته من الرابط الدائم أعلى التطبيق. الملف الثابت public/downloads/madar-overview.docx متاح دون إنشاء تقرير أو الاتصال بـ CelesTrak.

## الخصوصية والحماية

يمكن إيقاف «حفظ عملي على هذا الجهاز» من لوحة الخصوصية للعمل دون حفظ بين الجلسات، أو مسح بيانات مدار المحلية. أزيل تحميل الخطوط الخارجية وأضيفت سياسة حماية للمحتوى. تعمل ضوابط الخدمة البديلة وتنظيم الطلبات عند نشر إصدار Cloudflare الجديد. راجع SECURITY.md لتفاصيل الحماية وحدود الاستضافة والتخزين، وشغّل npm run audit لفحص الاعتماديات المعروفة.

نُشرت نسخة main مباشرة على Cloudflare في 14 أكتوبر 2026. ربط النشر التلقائي يحتاج تفويض Cloudflare للوصول إلى مستودع GitHub من إعدادات Builds؛ اتصال كل خدمة بـChatGPT لا يمنح هذا التفويض تلقائيًا. يتيح مسار Verify Cloudflare production في Actions تشغيل اختبارات النسخة المنشورة يدويًا.

## معلومات المهام الموثقة

يُنتج البناء 774 ملفًا موثقًا من data/mission-programs.json، منها 767 وصفًا لم يكن موجودًا في الفهرس الأساسي. تُطابق الأسماء وأرقام NORAD مع لقطة الهوية والمدارات في الفهرس المحلي؛ لا تُطبق قواعد أسماء تلقائيًا على أقمار جديدة أثناء الاستخدام. تشمل المصادر الجهات المشغّلة وNASA وESA وDLR ووزارة الجيوش الفرنسية وقوة الفضاء الأمريكية. يميّز العرض بين وصف خاص بالقمر، والغرض المنشور للمنظومة، والتصنيف العام. وصف المنظومة لا يثبت تفاصيل حمولة كل قمر أو حالته التشغيلية. لا تُخمن المهام غير المعلنة ولا تُنشأ مدارات لأقمار بلا عناصر منشورة. تظهر روابط المصادر وتاريخ مراجعة الأوصاف في التفاصيل، وترافق مراجع المهام تقارير Word.

شغّل npm run check لفحص مطابقة الهويات، وتمييز مستوى التوثيق، والتعامل مع غياب ملف الإثراء. تظل لقطة الهوية الأساسية بتاريخ 13 أكتوبر 2026 منفصلة عن مراجعة أوصاف المهام في 14 أكتوبر 2026.

## المدارات الحديثة وحداثة البيانات

تُطلب بيانات CelesTrak بصيغة JSON وفق حقول OMM، وتُمرر إلى json2satrec مباشرة دون تحويلها إلى TLE أو اختصار أرقام NORAD الطويلة. يبقى TLE مدعومًا للنسخ الاحتياطية والمفضلة القديمة. يستخدم العرض الكثيف وتقارير المرور والتحليل والحفظ البنية الموحدة نفسها.

تُحفظ استجابات المصدر لمدة ساعتين؛ لا يتجاوز زر فحص التحديث هذه الفترة. بعد استجابة HTTP غير ناجحة تتوقف الطلبات إلى المصدر لفترة التحديث، وتعرض الواجهة سبب التوقف مع آخر نسخة صالحة أو البديل المحلي. لا يُستبدل وقت الجلب القديم بوقت جديد عند استخدام التخزين أو البديل. تُحفظ قوائم المتابعة الكبيرة في IndexedDB مع دعم ترحيل السجلات القديمة، ويحترم ذلك خيار الخصوصية الحالي.

تعرض لوحة حداثة البيانات تاريخ العناصر ووقت الجلب والصيغة والمصدر والابتعاد الزمني عن وقت العرض. التصنيف الزمني مؤشر حداثة، وليس تقديرًا رقميًا لخطأ الموقع أو ضمانًا لصحة التنبؤ. المواضع محسوبة بـSGP4؛ لا يصل قياس جديد كل ثانية، ولا يُحمّل أرشيف مداري خاص بالتواريخ القديمة. تُظهر البطاقة فوق الجزء المرئي من الشاشة وتُغلق بزر الإغلاق أو Escape.

يتضمن npm run check مقارنة متجهات موضع وسرعة مع الحالة 00005 المنشورة في حزمة Vallado / CelesTrak AIAA-2006-6753، وفحص OMM ذي رقم من ست خانات ومسار العمال والتقارير والتخزين المؤقت. ملفات الاختبار ذات الست خانات مصطنعة وموسومة لذلك؛ لا تُضاف إلى فهرس الأقمار المنشور.

## البحث وتصفح النتائج

يدعم البحث الأرقام العربية والفارسية إلى جانب الأرقام اللاتينية، وأسماء الأقمار والمنظومات المنشورة والمعرّف الدولي. يمكن الجمع بين كلمات البحث، وتُطبّق جميعها مع تصفية الدولة وقائمة المتابعة. تعرض القائمة 100 نتيجة في كل صفحة، ويمكن الوصول إلى جميع النتائج بزرّي السابق والتالي؛ لا يحد ذلك من الأقمار المرسومة على الكرة أو من نطاق التقرير الذي يُختار في قسمه.

تظهر مع كل نتيجة فئة البعد الزمني عن وقت العرض (ضمن 24 ساعة، أو بين 24 و72 ساعة، أو أبعد من 72 ساعة)، إلى جانب مستوى توثيق المهمة. هذان مؤشّران منفصلان: الحداثة لا تثبت الدقة، ووصف مهمة المنظومة لا يثبت حمولة القمر أو حالته التشغيلية.

## دليل الاستخدام والتعريفات

يمكن فتح دليل عربي من أعلى الصفحة يشرح البحث والمتابعة والتقارير وحدود النتائج. يحتوي على قاموس محلي قابل للبحث مع الاسم الإنجليزي الكامل للاختصارات، والمعنى العربي، وروابط مرجعية؛ يظل المحتوى متاحًا دون طلبات شبكة إضافية. تفرق التعريفات بين المصطلح والاختصار ورمز الوحدة واسم الخدمة، وبين حداثة المدار وتوثيق المهمة.

## ترتيب النتائج وتصفية الحداثة

يمكن ترتيب الدليل بالاسم أو رقم NORAD أو تاريخ العناصر (الأحدث أولًا)، أو إبقاء ترتيب المصدر. تصفية الحداثة تستخدم الفارق المطلق عن وقت العرض الحالي أو المختار: ضمن 24 ساعة، أو ضمن 72 ساعة، أو أبعد من 72 ساعة. تتجدد النتائج عند عبور حد زمني دون إعادة فرز الفهرس كل ثانية، وتنعكس التصفية على القائمة والكرة والمتابعة. ترتيب التاريخ يختلف عن القرب الزمني؛ قد يكون التاريخ الأحدث بعيدًا عن تاريخ عرض قديم.

يحفظ التطبيق اختيارات التصفية والترتيب وفق إعداد الخصوصية. يعيد زر الضبط البحث والدولة والحداثة والترتيب إلى قيمها الافتراضية ضمن المجموعة أو الأنواع أو المتابعة الحالية، دون تغيير نطاق التقارير أو حذف المتابعة.

## نسخ المتابعة واستعادتها

يوفر قسم «نسخ قائمة المتابعة واستعادتها» ملف JSON بإصدار محدد، يتضمن جميع أقمار المتابعة وعناصرها المدارية دون التأثر بتصفية العرض. تتم قراءة الملف محليًا دون رفعه، مع حد 20 ميغابايت و20,000 سجل، ومعاينة الصالح والمستبعد والمكرر قبل الدمج. لا تحذف الاستعادة عناصر القائمة الحالية، ولا تستبدل عناصر أحدث بأقدم منها.

تُعاد وسم بيانات الملف بأنها مستوردة ويُحذف منها ادعاء وقت الجلب أو المصدر، مهما كان محتوى الملف. فحص البنية لا يثبت صحة مصدر العناصر. الاستعادة تحترم إعداد الحفظ الحالي، ويمكن تنزيل نسخة يدويًا حتى في وضع الجلسة فقط. الملف المنزّل يبقى في مكان التنزيلات ولا يمسحه زر مسح بيانات المتصفح داخل مدار.

## الرسم والحسابات عند عدم ظهور الخريطة

يتوقف رسم الكرة وطلب حساب مواقع الفهرس الكامل حين تخرج الخريطة من الشاشة، ويستمر تحديث معلومات القمر المحدد عند الحاجة. عندما تُخفى علامة التبويب، تتوقف أيضًا التحديثات الدورية للواجهة. عند العودة تُحسب المواقع لوقت العرض الحالي، مع احترام الإيقاف اليدوي أو التاريخ المحدد؛ لا يغير هذا السلوك حالة الإيقاف التي اختارها المستخدم.

تستخدم الواجهة Page Visibility وIntersectionObserver، مع بديل يعتمد على التمرير وتغيير الحجم عند غياب المراقب. تُهمل نتائج حساب المواقع التي تكتمل خارج العرض، ولا تُرسل طلبات الحساب المعلقة حينها؛ وتُطلب نتيجة مناسبة عند العودة. فحوص دورة الرسم تختبر التوقف والاستئناف وغياب المراقب، ولا تقدم نسبة توفير بطارية أو قياسات Core Web Vitals.

## ملخصات التقارير ورسومها

يتضمن التقرير العادي والمقارن إحاطة لكل فترة: عدد الأقمار والمرور، أطول مرور، أكثر مقطع ساعة ازدحامًا بالدخول (من بداية الطلب)، ومجموع المدد مقابل اتحادها. اتحاد المدد يقيس زمن وجود قمر واحد على الأقل داخل الحدود؛ لا يتكرر فيه الزمن عند تزامن أكثر من قمر. آخر مقطع قد يكون أقصر من ساعة، وعند تعادل العدد يُعرض الأسبق.

تُحسب مؤشرات المصدر والحداثة لكل الأقمار المفحوصة، بما فيها التي لم يُكتشف مرورها. يُستخدم أكبر فرق مطلق بين تاريخ العناصر وطرفي الفترة لتصنيف 24/72 ساعة؛ هذه ليست نسبة لدقة التنبؤ. تُحسب نسب اكتمال الدولة والمهمة على الأقمار المختلفة المكتشفة فقط، مع الفصل بين المهمة الفردية ووصف المنظومة في التفاصيل. تبقى مؤشرات المجموعات غير المتاحة في التقارير القديمة موسومة بذلك إلى إعادة الحساب.

الخريطة رسم مبسط بالدرجات لحدود Natural Earth وعينات مسار SGP4 لأول 40 حالة مرتبة زمنيًا، بحد 61 نقطة لكل مرور؛ تعرض بداية الجزء المحصور في الفترة، ولا تعرض تغطية مستشعر. الخط الزمني يعرض أول 12 حالة مع التاريخ والتوقيت المحددين. تُوضح حدود الرسم والمسارات غير المتاحة؛ تبقى كل النتائج في جداول Word. يمكن تمرير الرسوم أفقيًا على الهاتف، وتُدرج نسخ PNG في Word العادي والمقارن.

يفحص `scripts/check-report-insights.mjs` تداخل المدد وحدود الحداثة والمصادر المستوردة والمفقودة. ويولّد `scripts/check-browser-reports.cjs` من العامل الحقيقي مستندي Word ضمن آثار اختبار المتصفح، ويفحص اختيار الفترة والخرائط الفارغة وحد خط التاريخ وتخطيط الهاتف. بيانات هذه الحالات مصطنعة وموسومة TEST ONLY ولا تدخل الفهرس المنشور.

## المراجعة والتصدير ورصد الموقع

تعرض مقارنة الفترات عدد المرور لكل ساعة ونسبة اتحاد مدد الوجود من طول الفترة، مع إبقاء العدد الخام والحالات المحصورة وتحذير تداخل الفترات. الصادرات تشمل CSV بترميز UTF-8 مع BOM لفتحه في Excel، ونسخة طباعة كاملة يمكن حفظها PDF من المتصفح. تُحمى الخلايا النصية في CSV من تفسير الأسماء كصيغ. لا يُقدّم زر CSV ملف XLSX.

يحفظ كل تقرير جديد معرّفًا فريدًا ووقت إنشاء ثابتًا وإصدار الحساب والمكتبة وبصمة SHA-256 للقطة المدارات والمعاملات. تتاح اللقطة بصيغة JSON للمراجعة وإعادة الحساب برمجيًا باستخدام المصدر المحفوظ؛ ليست شهادة لصحة المصدر ولا يوجد استيراد تلقائي لهذا الملف. التقارير القديمة تُوسم عند غياب اللقطة، ولا تُنسب لها مدارات حالية بديلة.

يوفّر قسم رصد الموقع حسابًا محليًا للقمر المحدد أو حتى 500 قمر في المتابعة، لمدة تصل إلى 24 ساعة، بخطوة عشر ثوانٍ وصقل حدود المرور إلى نحو ثانية. الإحداثيات بالدرجات وارتفاع الموقع بالمتر فوق مرجع WGS84. النتائج زاوية الارتفاع فوق الأفق، والسمت من الشمال باتجاه عقارب الساعة، والمسافة المائلة عند ذروة تقديرية. يُحجب السمت قرب نقطة الرأس (89.9° فأعلى) لعدم استقراره. تُستبعد نتائج القمر كاملة عند تعذّر الحساب، ولا يُفترض خلو السماء من الأقمار عند النتيجة الصفرية. لا يُنمذج الضوء أو الظل أو الطقس أو التضاريس أو الانكسار الجوي؛ المرور الهندسي لا يضمن رؤية بصرية. يُحفظ تقرير الموقع وفق إعداد الخصوصية وتتاح له Word وCSV والطباعة ولقطة المدارات.

### الطيران والأجسام الجوية

حل هذا القسم محل «مواقعي والبيانات المحيطة والسجل الميداني». يعرض الإصدار الأول مسارات مستوردة أو مُدخلة يدويًا للطائرات والدرونز والصواريخ/مركبات الإطلاق والبالونات وأجسام أخرى، مع مخطط إحداثيات وتصفية وسجل اتصال مستقل. لا يتصل بمصدر طيران حي ولا يكتشف الأجسام غير المدرجة. لم يُدمج OpenSky دون اتفاق الاستخدام التشغيلي المطلوب. أزيل ربط الطقس والزلازل وصلاحيات الاتصال بمصدريهما.

CSV UTF-8: العناوين `objectId,name,kind,time,lat,lon,altitudeM,speedMps,headingDeg,source`؛ أول ستة حقول مطلوبة. النوع `aircraft|drone|rocket|balloon|other`، الوقت ISO مع Z أو فرق توقيت صريح؛ الدرجات للإحداثيات والاتجاه، المتر للارتفاع عن سطح البحر التقريبي، م/ث للسرعة. القيم الاختيارية الفارغة تعني «غير متاح»، ولا تستنتج قيم مفقودة. حتى 200 جسم و5000 عينة و1000 سجل اتصال و5MB للملف. يعرض الجدول أحدث 200 عينة للجسم والتصدير يشمل الجميع. المعاينة تسبق الدمج، والتعارض يرفض الملف دون استبدال بيانات قائمة. النسخة JSON تضم السجلات كاملة. الحفظ عبر StateStore وفق وضع الخصوصية الحالي، دون رفع الملفات.

خط النظر يحسب موضع القمر المحدد عند أحدث عينة للجسم باستخدام ارتفاع معلوم وSGP4. يرفض العناصر القديمة بالنسبة إلى العينة، ويعرض زاوية الارتفاع والمسافة وحداثة العناصر. يهمل التضاريس والعوائق والترددات والهوائيات، وليس دليل اتصال أو تغطية خدمة. سجلات الاتصال المُدخلة تتطلب المصدر والمرجع وتُعرض دائمًا «غير متحقق منها مستقلًا»؛ استقبال GPS وحده لا يثبت اتصالًا ثنائي الاتجاه.
