## إعادة القياس

ابدأ بنسخة نظيفة من الإصدار المرجعي أعلاه؛ استخدم Node 22 كما في CI. احتفظ بالمخرجات الجديدة في مجلد بتاريخ جديد حتى لا تطمس هذا السجل.

```sh
npm ci --ignore-scripts
npm run check
npm run format:check
npm run audit
npx playwright install chromium
MADAR_PERF_STABLE=1 MADAR_PERF_OUTPUT=test-results/performance-candidate.json node scripts/measure-browser-performance.cjs
```

بقية الأدلة: `source-files.json` لبصمات المصادر، `assets.json` لأحجام وبصمات الأصول المبنية، `manual-versions.json` للمراجع اليدوية، `html-resources.json` لإعلانات HTML، و`inventory-summary.json` للملخص العددي.
