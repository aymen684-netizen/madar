## التغيير

- ينفذ `npm run build` توليد `build/asset-manifest.json` بعد تجهيز الحماية والأصول وملفات المهام.
- تربط الخريطة المسار النسبي لكل ملف داخل `public/` ببصمة SHA-256 كاملة وحجمه بالبايت.
- تشمل الملفات المستعادة والمولدة والعمال وإعدادات الاستضافة الموجودة في المجلد.
- تُقرأ الملفات بتدفق، وتُرتب المسارات ترتيبًا ثابتًا، ولا يتضمن الناتج وقتًا أو مسارًا مطلقًا.
- يعاد إنشاء الجدول كاملًا في كل مرة، فلا تبقى فيه ملفات حُذفت. يُرفض الرابط الرمزي والنوع غير الاعتيادي.
- تستخدم `dev` و`deploy` و`check` سلسلة البناء نفسها؛ فشل توليد البصمات يوقف الأوامر اللاحقة.
- تفحص CI الخريطة ضمن `npm run check`، وترفعها كأثر `asset-fingerprints`، وتختبر بناء Worker دون نشر.

الخريطة خارج مجلد النشر وغير متتبعة في Git، فلا تدخل في حساب نفسها أو تغير قائمة موارد الشبكة.
العناوين اليدوية `?v=NN` لم تُستبدل في هذه الخطوة؛ تحديث المراجع في HTML وJavaScript والعمال
واختبار توافق سياسة الشبكة والتحديث من نسخة مخزنة هي المرحلة التالية. عند إعادة كتابة ملف مستقبلًا،
يجب حساب بصمته من البايتات النهائية ومعالجة اعتمادياته، ولا يكفي تطبيق بصمة المصدر قبل إعادة الكتابة.

## حدود التحقق والمتابعة

تعذر تثبيت Chromium المحلي: انتهى تنزيل الأرشيف بخطأ في بنية ZIP قبل تشغيل التطبيق.
لهذا تُراجع اختبارات المتصفح والأداء في GitHub Actions على رأس طلب الدمج نفسه؛
السجلات المحلية أعلاه لا تدعي نجاح المتصفح. حالة CI النهائية ورابط تشغيلها تسجل في وصف طلب الدمج.
لا يستنتج تحسن أداء من هذا التغيير؛ أصول المتصفح مطابقة لخط الأساس.
لم يجر دمج أو نشر إنتاجي في هذه المهمة.

للإعادة من نسخة نظيفة:

```sh
npm ci --ignore-scripts
npm run check
npm run format:check
npm run audit
WRANGLER_SEND_METRICS=false npx wrangler deploy --dry-run --outdir build/worker
```

لتجربة تكرار البناء: احفظ نسخة من `build/asset-manifest.json` خارج `public/`، ثم شغل
`npm run build` ثانية وقارن الملفين بايتًا ببايت.
