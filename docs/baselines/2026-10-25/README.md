# جزء الصباح — معاينة مراجع HTML بالبصمات — 25 أكتوبر 2026

القاعدة هي رأس طلب الدمج [#82](https://github.com/aymen684-netizen/madar/pull/82)
عند `fd0a1b22e7cc2302d2946d739b0362704a89c75e`، وهو مفتوح وغير مدمج عند البدء.
يُراجع هذا الجزء في طلب تابع له حتى تبقى إضافة خريطة البصمات منفصلة عن استخدامها.

## المنجز

ينشئ `npm run build:html-preview` نسخة مستقلة داخل `build/html-preview/`،
ويستبدل مراجع الملفات المحلية في خصائص `src` و`href` ببصمات SHA-256 كاملة.
الناتج يحدّث **91 مرجعًا**، منها **84 مرجع إصدار يدويًا** في الصفحة.
تتغير `index.html` وحدها في المعاينة؛ بقية الملفات الـ379 تطابق الأصول المجهزة الأصلية.
لا يعيد المولد كتابة المصادر داخل `public/`.

تُحفظ خريطة البايتات النهائية في `build/html-preview-manifest.json`،
ومراجع الصفحة قبل التحديث وبعده في `build/html-preview-report.json`.
الخريطتان والتقرير من نتائج بناء قابلة لإعادة الإنتاج، ويرفعها CI ضمن أثر البصمات.

## التحقق

- نجح التثبيت النظيف والفحوص العامة والتدقيق المحلي.
- نجحت اختبارات استبدال الخصائص مع الحفاظ على التعليقات والنصوص الحرفية وخصائص العناصر الأخرى والروابط الخارجية.
- بقي ترتيب تحميل السكربتات نفسه، وعملت المسارات النسبية تحت جذر الموقع ومسار مشروع فرعي.
- طابقت كل بصمة في عناوين المعاينة بايتات الملف المقصود.
- تغيير ملف CSS غيّر عنوانه وحده بين مراجع الأصول، وتغيرت بصمة الصفحة التي تشير إليه.
- أعطت إعادة التوليد HTML وخريطة مطابقين بايتًا ببايت؛ وأزيلت مخرجات سابقة لم تعد موجودة.
- رُفضت الخريطة القديمة والملف المفقود والاستعلام غير المتوقع ومسار الخروج من مجلد الصفحة.
- تخدم وظائف المتصفح والأداء في CI نسخة المعاينة نفسها؛ النتيجة النهائية ورابط تشغيلها في وصف طلب الدمج.

الأرقام والبصمات في [verification.json](verification.json)،
وسجلات [الفحوص](check.log) و[اختبارات HTML المركزة](html-tests.log) و[التنسيق](format.log) و[التدقيق](audit.log).

## المتبقي لاستكمال المهمة

تأتي مراجع JavaScript و`new Worker` و`importScripts` والتحميل الديناميكي بعد هذه المعاينة،
مع حساب البصمات بعد تحديث الاعتماديات ومعالجة سياسة الشبكة بدقة.
النسخة الحالية تغيّر عناوين HTML فقط؛ قد تعيد JavaScript كتابة بعض الروابط عند التفاعل كما تفعل حاليًا.
يلزم أيضًا اختبار الانتقال من النسخ المخزنة وربط بوابة الإصدار بالناتج الذي اجتاز التحقق.
أوامر النشر وإعدادات الاستضافة ما زالت تستخدم `public/`؛ هذا الجزء لا يفعّل معاينة HTML كناتج إنتاج.

```sh
npm ci --ignore-scripts
npm run check
npm run build:html-preview
npm run format:check
npm run audit
```
