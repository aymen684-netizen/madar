# استكمال 25 أكتوبر — مراجع JavaScript والعمال والنسخ المخزنة

يبني هذا الجزء على طلب الدمج [#83](https://github.com/aymen684-netizen/madar/pull/83)
عند `5ccd1ea8fc7c5bf5b47927f634ab9d8074c0c1ed`، وهو مفتوح وغير مدمج عند البدء.

## الناتج

ينتج `npm run build:runtime-preview` معاينة مستقلة ذات **380 ملفًا** في `build/runtime-preview/`،
ويحدّث **158 مرجعًا**: 91 في HTML و67 في JavaScript، بينها 126 مرجع إصدار رقمي في المدخلات الحالية.
فُكّ تركيب مرجعي التحميل المتغيرين السابقين في لوحة المرور والنبذة إلى مسارات كاملة قابلة للفحص.
تتضمن المعاينة أيضًا خريطة بصمات **243 مسارًا ديناميكيًا** للأعلام ونسخ البيانات النصية الاحتياطية.

تُحسب البصمات من الاعتماديات إلى الملفات التي تستدعيها، بما في ذلك `new Worker` و`importScripts`
والتحميل المؤجل والبيانات والصور والتنزيلات، ثم تُحدّث الصفحة ببصمات الملفات النهائية.
تبقى مكتبات الطرف الثالث مطابقة لبايتات المدخلات. خريطة المسارات المتغيرة تحتوي الأصول الطرفية فقط،
لتجنب بصمة تشير إلى نفسها. لا يُغيّر المولد المصادر أثناء بناء المعاينة.

تقبل سياسة الشبكة بصمة SHA-256 كاملة أو الأرقام القديمة، مع بقاء قائمة الملفات وقيود الوجهات والطرق
ورفض تكرار `v` والمعاملات الإضافية والبصمات الناقصة أو ذات الأحرف الكبيرة.

## التحقق

- نجحت الفحوص المحلية العامة واختبارات البصمات وHTML وJavaScript، والتنسيق والتدقيق.
- تطابق كل عنوان ثابت وديناميكي بايتات الملف النهائي، وأعادت عملية التوليد النتائج نفسها.
- تغيير اعتماد داخل Worker غيّر بصمته وبصمات مستدعيه وصولًا إلى الصفحة، دون تغيير ملف مستقل.
- رُفضت دورات الاعتماد والخريطة القديمة والاستعلامات غير المتوقعة قبل استبدال المعاينة الصالحة السابقة.
- أُضيف اختبار متصفح مستقل للانتقال من الإصدار الرقمي السابق إلى المعاينة تحت `/project/`.
  لا يستخدم اعتراض طلبات Playwright الذي يعطّل ذاكرة HTTP؛ يثبت أولًا استخدام النسخة القديمة من الذاكرة،
  ثم يتحقق من العناوين الجديدة والتحميل الديناميكي وعمل Worker حقيقي وبقاء اللغة والخصوصية والمفضلة.
- المتصفح غير متاح محليًا؛ نتائج CI النهائية وروابط التشغيل تُثبت في وصف طلب الدمج.

تخدم وظائف المتصفح والأداء في CI المعاينة الجديدة نفسها. الأدلة المحلية في [verification.json](verification.json)
وسجلات الفحوص المرفقة. يُرفع بيان البصمات وتقرير المراجع ودليل اختبار الذاكرة ضمن نتائج CI.

## حدود هذا الجزء والخطوة التالية

يفترض اختبار الانتقال إعادة التحقق من HTML مع بقاء الأصول القديمة حديثة داخل ذاكرة HTTP.
هذا تحقق مختبري؛ يجب التحقق من ترويسات الاستضافة الفعلية عند تفعيل الناتج في بوابة الإصدار.
أوامر النشر وإعدادات الاستضافة لا تزال تستعمل `public/`، وتوصيلها بالناتج المتحقق منه خطوة تالية مستقلة.
لا يتضمن هذا الجزء دمجًا أو نشرًا.

```sh
npm run check
npm run build:runtime-preview
npm run format:check
npm run audit
MADAR_CACHE_BASELINE_ROOT=cache-baseline/public node scripts/check-browser-asset-update.cjs
```
